# Data README

## Source

**Dataset**: German Credit Data (StatLog)  
**Original contributor**: Prof. Dr. Hans Hofmann, Institut für Statistik und Ökonometrie, Universität Hamburg  
**UCI Repository**: <https://archive.ics.uci.edu/dataset/144/statlog+german+credit+data>  
**License**: Creative Commons Attribution 4.0 International (CC BY 4.0)

## Files

| File | Description |
|------|-------------|
| `raw/german.data` | Original space-separated file, 1 000 rows × 20 features + 1 target |
| `processed/train.csv` | Training split (80 %) with engineered columns – generated by `src/data_prep.py` |
| `processed/test.csv` | Test split (20 %) – generated by `src/data_prep.py` |

## Column reference

| # | Column name (after renaming) | Type | Description |

| 1 | `checking_status` | cat | Status of existing checking account |
| 2 | `duration_months` | num | Loan duration in months |
| 3 | `credit_history` | cat | Past repayment record |
| 4 | `purpose` | cat | Reason for the loan |
| 5 | `credit_amount` | num | Loan amount in DM |
| 6 | `savings_status` | cat | Savings account / bonds balance |
| 7 | `employment_since` | cat | Length of current employment |
| 8 | `installment_rate` | num | Monthly instalment as % of disposable income |
| 9 | `personal_status_sex` | cat | Sex + marital status (sensitive proxy) |
| 10 | `other_debtors` | cat | Co-applicant or guarantor |
| 11 | `residence_since` | num | Years at current address |
| 12 | `property` | cat | Main property type |
| 13 | `age` | num | Age in years (sensitive attribute) |
| 14 | `other_installment` | cat | Other instalment plans |
| 15 | `housing` | cat | Rental / own / free |
| 16 | `existing_credits` | num | Number of credits at this bank |

## Engineered columns (added by `data_prep.engineer_features`)

| Column | Derivation |
|--------|-----------|
| `gender` | `male` if `personal_status_sex` ∈ {A91, A93, A94}, else `female` |
| `age_group` | Pd.cut buckets: <30, 30-45, 45-60, 60+ |
| `target` | Remapped: original 1 → 1 (approved), original 2 → 0 (rejected) |

## Privacy notice

This dataset does **not** contain real personal data. It was collected in the
1970s in West Germany and has been fully anonymised by the original contributor.
All values are coded (e.g. A11, A32) and no individual can be identified.

The `gender` column is derived from the `personal_status_sex` code and is used
**only** for fairness auditing purposes — it is not used as a model input feature.
